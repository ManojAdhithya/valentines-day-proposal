# valentines-day-proposal
This code contains HTML that can be used for Valentines day proposal

- Save your file: Make sure your code is saved as index.html.

- Go to this website: Open Tiiny.host on your computer.

- Upload: Drag and drop your index.html file into the big box on the screen.

- Name it: It will ask for a "Link Name". Type something cute like special-question-for-you.

- Launch: Click "Upload" or "Publish".

- Send: It will give you a link (e.g., special-question-for-you.tiiny.site). Copy that link and send it to her!
